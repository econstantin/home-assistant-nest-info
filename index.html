Home Assistant Nest

A personal integration connecting the owner's Google Nest devices to the owner's Home Assistant installation.

What the integration does

With the owner's Google account authorization, Home Assistant uses Google's Smart Device Management API to read the selected devices' status and receive updates through Google Cloud Pub/Sub. It allows the owner to monitor temperature and humidity and control supported thermostat settings from Home Assistant.

This integration is for the owner's personal use. It is not a public service, and this website does not provide account sign-in or thermostat controls.

Privacy and access

The owner chooses which devices to authorize through Google. See the privacy policy for how the integration uses and stores that data and how to revoke access.

Terms of use

This personal integration is provided as is, without warranties or guarantees of availability. The owner remains responsible for thermostat settings and automations. It is not an emergency or safety monitoring service.
